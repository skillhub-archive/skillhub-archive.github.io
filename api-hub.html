How this Sprint Works

Each session is about 1h45 of hands-on work in a real API client plus a built-in 15-minute review. No programming language is used anywhere in this track: the client you install in Session 1 is the whole practice environment, for both sending requests and, later, designing them. The arc: speak HTTP fluently, then consume APIs the way a professional does, then design a contract of your own, then wire two systems together, then ship one real integration end to end.

The Five Levels

Sessions ship one at a time, so each can absorb what was learned building the last one. Work them in order, Session 1 through 10, since later sessions build on earlier ones and re-test them. Tick the box when you finish a session so this page tracks where you are. Nothing here needs a paid tier; the one thing Level 3 needs beyond Session 1's setup is a free account, and Session 1 tells you exactly when that becomes necessary.

Using this Hub

Go in order. Every session assumes the one before it. Levels 3 through 5 in particular build directly on the request/response fluency Level 1 sets up.

One real API client, all ten sessions. Session 1 walks you into Postman with no account at all, and you stay in the same tool the whole way through: sending requests through Level 2, then designing and mocking your own through Levels 3 to 5.

Nothing here is tied to one employer's API. Every session practices against free, public services built for exactly this, so what you learn transfers to any API you meet afterward, not just the one you use at work.

Two hours is a guide, not a target. Finishing in ninety minutes is fine, and so is taking three hours.

Tick sessions as you finish them so the panel above stays honest, and export a copy if you switch machines.

Top 5 Resources

Four of these five are free. Each is here for a specific job, so use them where they help rather than reading them end to end.

01

Postman Academy

Free · official

Postman's own free, self-paced learning platform, covering everything from sending your first request to building automated test collections. The API Fundamentals path lines up closely with this track's Levels 1 and 2, from Postman's own angle.

academy.postman.com
During: alongside Levels 1–2 if you want a second explanation of the same ideas.
02

MDN Web Docs: HTTP

Free · the reference

Mozilla's HTTP documentation is the closest thing the web has to an authoritative, vendor-neutral reference for methods, status codes and headers. Dense and not a teaching text, which is exactly why it belongs here: once you know what a thing is called, this is where you learn everything about it.

developer.mozilla.org/…/Web/HTTP
After: for precision on a status code or header, not for learning a concept.
03

REST API Tutorial (restfulapi.net)

Free

A focused, free guide to REST's actual design principles: resources, verbs, statelessness, HATEOAS. Most useful once you reach Level 3, where you go from calling APIs to designing one of your own.

restfulapi.net
During: Level 3, when you start designing rather than just consuming.
04

JSONPlaceholder

Free · practice API

The free fake REST API this track practices against from Session 1 onward. Worth bookmarking on its own: whenever you want to test an API client, a script, or an idea, this is a safe, stable target that accepts every verb and never needs a key.

jsonplaceholder.typicode.com
During: every session in Levels 1–2, then anytime you want a quick real target.
05

Designing Web APIs

Paid · Jin, Sahni & Shevat · O'Reilly

The best single book for the design half of this track: how to model resources, choose a shape developers will actually enjoy using, and manage an API once it has real callers. Case studies from Slack, Stripe and GitHub throughout.

oreilly.com · Designing Web APIs
During: Levels 3 and 4, alongside designing your own contract.
