A. Defining and calling a function

A function is a named, reusable block of code. You define it once with the def keyword, and the indented lines beneath make up its body. Defining does not run the body, it just teaches Python the recipe. To actually run it you call the function by writing its name followed by parentheses. Define once, call as many times as you like.

def welcome():             # DEFINE the function (this does not run the body yet)
    print("Welcome aboard!")

welcome()                  # CALL it: now the body runs -> Welcome aboard!
welcome()                  # call again to reuse it -> Welcome aboard!

B. Arguments: positional, keyword & default

Most functions need inputs. The names you list in the parentheses of the def line are parameters; the actual values you hand over when you call are arguments. There are three ways to pass them:

  • Positional: arguments are matched to parameters by their order. First value fills the first parameter, and so on.
  • Keyword: you name the parameter explicitly with name=value, so order no longer matters.
  • Default: give a parameter a fallback value in the def (size="medium") and the caller can leave it out entirely.

These examples use return to hand the finished sentence back to the caller. You will meet return in full in the next concept; for now, read it as "this is the function's answer, sent back out so the caller can use it."

def order(item, qty, size="medium"):   # size has a DEFAULT value
    return f"{qty} {size} {item}"

print(order("coffee", 2))              # positional; size defaults -> 2 medium coffee
print(order("tea", 1, size="large"))   # keyword names the argument -> 1 large tea
print(order(qty=3, item="water"))      # keywords can go in any order -> 3 medium water

C. Return vs print (the big one)

This is the distinction that trips up almost everyone, so read it twice. print displays text on the screen and hands nothing back. return sends a value back to whoever called the function so you can store it in a variable and keep working with it. A function that only prints looks like it "worked", but the caller gets None (Python's word for "no value"), so there is nothing to reuse. Here is the trap, then the fix:

# The trap: this PRINTS but never RETURNS
def add_bad(a, b):
    print(a + b)           # shows the answer on screen...

result = add_bad(2, 3)     # prints 5, but hands nothing back
print(result)              # -> None (no return, so result is empty)

# The fix: RETURN the value so the caller can keep using it
def add_good(a, b):
    return a + b           # hands the number back to the caller

total = add_good(2, 3)     # total now holds 5
print(total * 10)          # you can keep computing with it -> 50

▶ watch the difference run step-by-step in Python Tutor

Rule of thumb: if another part of your program needs the answer, return it. Use print only when the whole point is to show something to a human right now.

D. Scope: local vs global

Before the example, the word: scope means where a variable is visible. A variable created inside a function is local, it exists only while that function runs and disappears the moment it finishes; code outside can't see it. A variable defined at the top level of your file is global, visible everywhere, including inside your functions. This is a feature, not a nuisance: it means a function's own variables never accidentally clash with the rest of your program.

budget = 1000              # a GLOBAL variable, defined at the top level

def spend(amount):
    remaining = budget - amount   # remaining is LOCAL: born here, gone after
    return remaining

print(spend(300))          # the function can READ the global -> 700
print(budget)              # the global is untouched -> 1000
# print(remaining)         # this would ERROR: remaining does not exist out here

The takeaway: functions can read a global value, but any variable they create lives and dies inside them. Reaching for a local variable from the outside is a NameError.

E. Docstrings, modules & imports

Two finishing touches that make functions professional and powerful:

  • A docstring is a triple-quoted string placed as the very first line inside a function. It documents what the function does, and tools (and help()) can read it. Think of it as the label on the box.
  • A module is simply a .py file full of reusable code, functions and values someone already wrote. Python's standard library ships hundreds of them. You bring one in with import, then reach into it with module.thing(). Or pull out just one name with from module import thing and use it without the prefix.
def greet(name):
    """Return a friendly greeting for the given name."""   # a docstring documents the function
    return f"Hello, {name}!"

import math                    # bring in the whole math module
print(math.sqrt(144))          # call into it with module.thing() -> 12.0

from random import randint     # or bring in just one name
print(randint(1, 6))           # now call it directly, no prefix -> a number 1 to 6 (changes each run)
Your turn The milestone: refactor into functions

This is your Session 4 milestone. Take the job-records idea from Session 3 and refactor it into a reusable function. Define total_with_tax(price, rate=0.1) that returns the price plus tax, give it a one-line docstring, then loop over a list of 3 job dicts and call your function for each. As a bonus, import the statistics module and print the average total. Turning a one-off script into clean functions is the whole point of today, so try it before peeking.

Show reference solution 
import statistics    # a standard-library module

def total_with_tax(price, rate=0.1):
    """Return the price plus a tax surcharge."""   # docstring
    return price * (1 + rate)

jobs = [
    {"name": "Move", "price": 300},
    {"name": "Pack", "price": 120},
    {"name": "Storage", "price": 80},
]
totals = []
for job in jobs:                       # reuse the function every loop
    name = job["name"]
    total = total_with_tax(job["price"])
    totals.append(total)
    print(f"{name}: ${total:.2f}")     # f-string + :.2f from Session 1

print(f"Average: ${statistics.mean(totals):.2f}")   # a module doing the math
