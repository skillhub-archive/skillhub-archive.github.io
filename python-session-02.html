A. Booleans & comparison operators

A Boolean (named after mathematician George Boole) is a value that is only ever one of two things: True or False. Note the capital letter and no quotes, True is a Boolean but "True" is just ordinary text.

You rarely type True yourself. Instead you ask a question with a comparison operator (a symbol that compares two values), and Python hands back a Boolean:

  • == equal to (two equals signs)
  • != not equal to
  • < > less than / greater than
  • <= >= less than or equal to / greater than or equal to

Reading them: the only operator that isn't self-explanatory is !=, in code ! means "not", so != reads as "not equal". One thing to watch: the = always comes second, so it is >= and <=, never =>.

age = 20
print(age == 20)   # is age equal to 20? -> True
print(age != 20)   # is age NOT equal to 20? -> False
print(age >= 18)   # is age 18 or more? -> True
print(age < 13)    # is age under 13? -> False

The one that trips everyone up: = vs ==. A single = assigns a value (you saw this in Session 1). A double == asks whether two values are equal. Mixing them up is the most common beginner bug.

x = 5            # assignment: put 5 into x
print(x == 5)    # comparison: is x equal to 5? -> True

B. Logical operators & truthiness

Real decisions often combine questions. Logical operators join Booleans together:

  • and is True only if both sides are True
  • or is True if at least one side is True
  • not flips a Boolean to its opposite
age = 20
has_ticket = True
print(age >= 18 and has_ticket)   # both true? -> True
print(age < 13 or has_ticket)     # at least one true? -> True
print(not has_ticket)             # flip True to its opposite -> False

Truthiness is Python's habit of treating ordinary (non-Boolean) values as True or False when it needs a yes/no answer. The falsy values (treated as False) are the "empty or zero" ones: 0, "" (an empty string), [] (an empty list), and None. Everything else is truthy (treated as True). The bool(x) function below just shows you how Python would judge each value:

print(bool(0))     # 0 is falsy -> False
print(bool(""))    # empty string is falsy -> False
print(bool("hi"))  # a non-empty string is truthy -> True
print(bool(42))    # any non-zero number is truthy -> True

C. if / elif / else

An if statement runs a chunk of code only when a condition is True. That chunk is called a block: the lines indented underneath the if. Python uses 4 spaces of indentation to know which lines belong together, and the condition line always ends with a colon :.

temp = 45
if temp < 50:
    print("Bring a jacket")   # indented, so it runs only when temp < 50
print("Have a good day")      # NOT indented, so it always runs

elif ("else if") checks another condition when the ones above it were False. else catches everything left over. Python reads top to bottom and runs the first match only, then skips the rest.

Why not just stack separate ifs? You can, but it is clumsy, each one re-checks from scratch and you have to hand-write the "in-between" ranges. The elif chain says it once, cleanly:

# The clunky way: separate ifs, each re-checks the range by hand
score = 72
if score >= 90:
    print("A")
if score >= 80 and score < 90:   # you must spell out the gap yourself
    print("B")
if score < 80:
    print("C")

# The clean way: an elif chain, only ONE branch can run
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")     # this one runs -> C

D. for loops & range

A for loop repeats a block once for each item in a sequence. To iterate just means to step through those items one at a time. The loop variable (here i) holds the current item on each pass.

range() generates a run of numbers to loop over. The key gotcha: range stops BEFORE the end number.

  • range(5) gives 0, 1, 2, 3, 4 (starts at 0, five numbers)
  • range(1, 6) gives 1, 2, 3, 4, 5 (start, up to but not including 6)
  • range(0, 10, 2) gives 0, 2, 4, 6, 8 (the third number is the step)
for i in range(3):     # i takes the values 0, then 1, then 2
    print(i)           # each pass prints the current i
# 0
# 1
# 2

E. while loops, break & continue

A while loop repeats as long as its condition stays True. Reach for it when you don't know the number of passes ahead of time (keep going until something happens), where a for loop fits when you know the count.

The trap: if nothing inside the loop ever makes the condition False, it runs forever, an infinite loop. You must change something each pass so it can eventually stop.

count = 3
while count > 0:          # keep looping while count is above 0
    print(count)          # prints 3, then 2, then 1
    count = count - 1     # this line is what eventually ends the loop
print("liftoff")          # runs once, after the loop stops

▶ watch the countdown run step-by-step in Python Tutor

Two ways to steer a loop from the inside:

  • break leaves the loop immediately, skipping whatever is left
  • continue skips the rest of this pass and jumps to the next one
for n in range(1, 6):     # n is 1, 2, 3, 4, 5
    if n == 4:
        break             # stop the whole loop the moment n hits 4
    print(n)              # prints 1, 2, 3 (never reaches 4 or 5)

And here is continue, which skips only the current pass and then carries on with the loop:

for n in range(1, 6):     # n is 1, 2, 3, 4, 5
    if n == 3:
        continue          # skip the rest of THIS pass only when n is 3
    print(n)              # prints 1, 2, 4, 5 (3 is skipped, the loop keeps going)

One more shape you'll meet in the drills: a deliberately endless while True: loop with a break inside. It's how you say "keep going until I decide to stop", the break is what ends it.

Your turn The milestone script

Write guess.py: store a secret number, then loop asking the user to guess it. Each guess, decide and print Too low or Too high, and stop the moment they get it right. This loops AND makes a decision, your Session 2 milestone, so try it before peeking.

Here is what it looks like when it runs. You type the numbers; the program prints everything else:

Guess (1-10)? 5      # program printed the prompt; you typed 5

Show reference solution 
secret = 8
guess = int(input("Guess (1-10)? "))   # ask once before the loop starts
while guess != secret:                  # keep looping until the guess is right
    if guess < secret:
        print("Too low")
    else:
        print("Too high")
    guess = int(input("Guess (1-10)? "))  # ask again each pass (this can end the loop)
print("Correct!")                        # runs once the guess matches
