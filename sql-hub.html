A focused sprint from confident code-reader to someone who can query, join, aggregate, and model real data, then call it straight from Python. How this Sprint Works

Each session is ~1h45 of hands-on work plus a built-in 15-minute review. You run everything in real SQLite (it ships with Python, zero install) using the sqlite3 shell or DB Browser for SQLite. The arc: get answers out of data, then combine and reshape it, then design and build it, and finally drive it from Python, the SQL half of the full-stack path your CTO named (SQL + Python + APIs + Git).

5
Levels, beginner → advanced, each with a clear "you can now…" milestone.
10
Two-hour hands-on workbooks you complete in SQLite, built on demand.
6
Practice modes each session: learn-and-do, predict, arrange, fill, write, recall.
∑
Cumulative review, later sessions re-test earlier ones (spaced practice).

Top 5 Resources

Curated for your goal, not a generic list. All five are free. Use the first three during the sprint for hands-on practice, and the last two as the authoritative references you'll keep returning to.

01

SQLBolt

Free

The smoothest interactive on-ramp there is: no signup, no install, you write real SELECT / WHERE / JOIN queries in the browser and it checks each one. Perfect second angle on Levels 1–2 fundamentals.

Use: during, Levels 1–2
sqlbolt.com
02

Mode SQL Tutorial

Free

Analytics-focused, the closest thing to the real reporting work you're aiming at. Its aggregation, join, and subquery lessons run in a live query editor and mirror Levels 2–3 exactly.

Use: during, Levels 2–3
mode.com/sql-tutorial
03

Select Star SQL

Free

A free interactive book that builds the mental model for writing SQL, not just the syntax, by working a real dataset. Read it alongside the sprint when you want the "why", especially for joins and aggregation.

Use: during + after, Levels 2–3
selectstarsql.com
04

SQLite Documentation

Free

The canonical reference for the exact database you're running. The syntax diagrams, datatype / type-affinity, CREATE INDEX and EXPLAIN QUERY PLAN pages are the primary source for Levels 4–5. Learning to read them is itself a career skill.

Use: reference, throughout (esp. Levels 4–5)
sqlite.org/docs.html
05

Python sqlite3 docs

Free

The standard-library module you'll use to call SQL from Python in Level 5: connections, cursors, ? placeholders, and row factories. The bridge between this track and your pandas work.

Use: during, Level 5 + reference
docs.python.org/3/library/sqlite3

Where to next

You finished the whole track: you can model a schema, query it, change it safely, and drive it from Python. This is not another level to clear, it is the view from the top of the sprint, two honest ways to keep climbing.

Try this: window functions

The one topic this sprint named but did not teach (the aside back in Session 6). Window functions rank rows, run totals, and compare a row to its group without collapsing the rows the way GROUP BY does, exactly the moves that power real reporting. They build straight on the joins and aggregates you already know, which is why they are the natural next climb rather than a fresh start.

Optional bonus workbook: there is now a hands-on window-functions session, a real workbook like the ten you just finished but deliberately outside the graded track, so opening it does not change your 10/10 completion. It teaches window functions on top of the joins, aggregates, CTEs and ROUND you already know.

Get it certified

These sprints cannot hand you a credential. If you want one that proves what you learned, here are the genuine, proctored exams (both are paid, and both were current as of 2026). Skip the "completion certificate" badges from course sites; these two are the real thing.

CERT · best match

Oracle Database SQL Certified Associate

Paid · exam 1Z0-071

The most on-target credential for this track: a pure-SQL exam covering SELECT, joins, subqueries, DDL and constraints, with no prerequisites. It is Oracle-flavored, but the core is the standard SQL you have been writing in SQLite all along.

Closest to what you learned
education.oracle.com · 1Z0-071
CERT · broader

Microsoft Certified: Azure Data Fundamentals

Paid · exam DP-900

Wider than pure SQL: core data concepts plus Azure data services at a beginner level, so it is lighter on hands-on querying. Worth it if you are heading toward cloud or Microsoft-stack data work rather than SQL depth.

If you are cloud / Azure oriented
learn.microsoft.com · DP-900

There is no single vendor-neutral "SQL certification" that carries broad weight, and SQLite itself has no exam (it is a library, not a product you certify on). The good news: the SQL you practiced here transfers to every one of these.
