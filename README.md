# Learning Hub

A collection of self-paced learning builds. First up: a 20-hour Python sprint.

## Python 20-Hour Sprint

A focused, hands-on course that goes from confident code-reader to someone who
ships small tools, calls APIs, and wrangles data. Five levels across ten
two-hour sessions, each an interactive "workbook" (learn-and-do, predict the
output, arrange and fill, write it yourself, rapid-recall flashcards, and a
quick-check quiz) with a milestone at every step.

### How to use these files

Each session is a **single self-contained HTML file** (styles and logic
inlined, no build step, no dependencies). Open any `.html` file in a browser to
use it, your progress is saved locally in that browser. The Hub is the roadmap
and progress tracker; start there.

### The arc

- **Level 1, Foundations:** variables and types through control flow.
- **Level 2, Data structures and reusable code:** lists, dicts, functions.
- **Level 3, Real-world Python:** files and CSV, errors, virtual environments and pip.
- **Level 4, APIs and integration:** requests, JSON, authentication, pagination.
- **Level 5, Data wrangling and shipping a tool:** pandas, then a capstone that
  pulls live data from an authenticated API, cleans and groups it with pandas,
  and writes a finished report file, organized into functions behind a
  `if __name__ == "__main__":` entry point.

The capstone (Session 10) is the whole sprint in one script.
