Where to next

You finished the whole track: you can write scripts, wrangle files and data, call real APIs, and ship a small tool end to end. This is not another level to clear, it is the view from the top of the sprint, two honest ways to keep climbing.

Try this next: object-oriented Python (classes)

This sprint stayed procedural on purpose: functions, dicts, and scripts, the fastest path to shipping tools. The natural next climb is classes and object-oriented programming, the way you bundle data together with the functions that act on it once a script grows past a handful of loose functions. It is also the one big topic that separates the two certifications below.

Where to learn it: the official Python tutorial, Classes chapter is the canonical reference, and Real Python's OOP guide (Real Python is already in your resources above) walks it with worked examples. Both run in the same VS Code setup you already have.

Hands-on bonus: there is now an optional Object-Oriented Python workbook ↗ in the same six-part format as the sprint sessions. It sits outside the graded ten and does not change your 10/10, it is extra ground to pick up when you are ready.

Get it certified

These sprints cannot hand you a credential. If you want one that proves what you learned, here are the genuine, proctored exams from the OpenEDG Python Institute (both are paid, and both were current as of 2026). Skip the "completion certificate" badges from course sites; these two are the real thing.

CERT · best match

PCEP, Certified Entry-Level Python Programmer

Paid · exam PCEP-30-02 · from $69

The most on-target credential for this sprint: an entry-level exam on exactly what Levels 1 to 3 taught, data types, containers, functions, conditionals, loops, and exceptions. No prerequisites, 30 questions, proctored online.

Closest to what you learned
pythoninstitute.org/pcep
CERT · next step

PCAP, Certified Associate Python Programmer

Paid · exam PCAP-31-03 · from $295

The step up: modules and packages, file processing, generators and closures, and object-oriented programming. It expects the classes topic above, which this sprint did not cover, so learn that first and then this exam is within reach.

After you learn classes
pythoninstitute.org/pcap

There is no single vendor-neutral "Python certification" that every employer recognizes, and for a tooling and automation role a portfolio of real scripts often speaks louder than a badge. If you do want one, the Python Institute pair above is the most established vendor-neutral option.
