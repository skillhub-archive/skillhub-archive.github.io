A. Get Python running

  • Install Python from python.org/downloads. On Windows, tick "Add python.exe to PATH" in the installer, this lets you type python anywhere.
  • Install VS Code, then its Python extension (search "Python" by Microsoft in Extensions).
  • Verify: open VS Code's terminal (Ctrl + `) and run python --version. You should see a version number.

A script is just a file ending in .py. Type code into it and run it. Here's the smallest possible one:

# hello.py
print("Hello from my first script!")   # Hello from my first script!

Two ways to run it, and they do the exact same thing:

  • Easiest: click the ▷ Run button in the top-right of the editor, or press Ctrl + F5. VS Code runs the file and shows the output in the terminal.
  • By hand: in the terminal, type python hello.py. This is literally what the Run button types for you, worth knowing so the button is never a mystery when something breaks.

For quick experiments there's also the REPL: type python in the terminal and enter one line at a time. Nothing is saved, it's a scratchpad for testing an idea.

B. Variables are labels you can move

A variable is a name pointing at a value, created with =. You can re-point it anytime. Names use snake_case, must start with a letter or _, and are case-sensitive.

first_name = "Sam"     # create
age = 30
age = age + 1          # re-point age at 31
print(first_name, age) # Sam 31

One subtlety worth locking in early: assignment is a snapshot, not a live link. If you write b = a + 1, that copies a's value at that moment into b; re-pointing a later does not reach back and change b.

Heads-up on print: when you give it several things separated by commas, it prints them with a space between, not a comma. So print(first_name, age) shows Sam 31, the commas in your code are just separators. To actually show a comma, put it in yourself: print(f"{first_name}, {age}").

C. Numbers & math operators

Two number types: int (whole, 42) and float (decimal, 3.14). You can ask any value what type it is with the built-in type() function: type(42) reports <class 'int'>, and type(3.14) reports <class 'float'>. The operators:

  • + - * add, subtract, multiply
  • / divide, always a float: 10 / 2 is 5.0
  • // floor divide, drops remainder: 7 // 2 is 3
  • % modulo, the remainder: 7 % 2 is 1
  • ** power: 2 ** 3 is 8
  • Normal precedence: * and / before + and -.

D. Strings & f-strings

A string is just text in quotes: "hello". That's it. An f-string is the same thing with one superpower, you put f before the opening quote, and anything inside { } gets swapped for its real value. So the difference is only about whether you need to drop a variable or a calculation into the text.

name = "Sam"
age = 30

# Plain string: fixed text, nothing to insert
print("Please enter your details")

# Inserting a value the OLD way: concatenation (joining strings end to end with +)
print("Hi " + name + ", age " + str(age))   # clunky, and you MUST str() the number

# The f-string way: cleaner, and it converts for you
print(f"Hi {name}, age {age}")               # Hi Sam, age 30

When to use which: plain string when the text never changes; f-string whenever you're building text out of data (a variable, a total, a calculation). With + you have to glue pieces and manually str() every number, one missed conversion is an error. The f-string just works, so it's the modern default. Once you have f-strings you'll almost never reach for + to build a message.

Some characters can't just be typed inside a string, a line break, for example. An escape is a backslash \ followed by a letter that stands in for one of them. The two you'll actually use: \n makes a new line, \t inserts a tab.

print("Line one\nLine two")
# Line one
# Line two   <- the \n split it onto two lines
print("Name:\tSam")
# Name:   Sam   <- the \t inserted a tab gap

And a few string tools you'll use constantly. The comment explains what each one does:

len("python")        # number of characters -> 6
"sam".upper()        # uppercase version -> "SAM"
"  hi  ".strip()     # trim spaces off both ends -> "hi"
"a,b,c".split(",")   # break into a list at each comma -> ['a', 'b', 'c']
"cat" * 3            # repeat the text 3 times -> "catcatcat"

E. Input, output & conversion

print() sends text out; input() reads text in. The text inside input("...") is the prompt, the message shown on screen telling the user what to type. It is not a value you fill in, the value is whatever the user types when the program runs.

The #1 trap: input() always hands back a string, even if the user types digits. Convert before doing math: int() for a whole number (int("30") gives 30), float() for a decimal (float("3.5") gives 3.5).

raw = input("Your age? ")   # show "Your age? ", grab what's typed (as text)
age = int(raw)              # convert that text into the number 30
print(f"Next year you're {age + 1}")

Here is what that looks like when it actually runs. You type the 30; everything else is printed by the program:

Your age? 30          # the code printed "Your age? "; you typed 30
Next year you're 31

One more f-string trick you'll want for the milestone below, since it deals with money: put :.2f right after a value to show it with 2 decimal places. So if tip is 10.0, then f"${tip:.2f}" prints $10.00 instead of $10.0, which is how dollars and cents should look.

Your turn The milestone script

Write tip.py: ask for a bill amount, ask for a tip percent, print the tip and total. This is your Session 1 milestone, do it without peeking first.

Show reference solution 
# get each value as text, then convert it, the two-step pattern from above
raw_bill = input("Bill amount? ")   # you type 50  ->  "50"
bill = float(raw_bill)              # convert to a decimal number: 50.0

raw_pct = input("Tip percent? ")    # you type 20  ->  "20"
pct = float(raw_pct)                # 20.0

tip = bill * pct / 100              # 50.0 * 20.0 / 100  =  10.0
print(f"Tip: ${tip:.2f}  |  Total: ${bill + tip:.2f}")

# :.2f means "show 2 decimal places", so 10.0 prints as 10.00 (looks like money)
# Tip: $10.00  |  Total: $60.00
# once comfortable, you can combine each pair: bill = float(input("Bill amount? "))
